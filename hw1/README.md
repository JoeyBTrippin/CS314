cat.c: program code is a self implementation of the basic cat function
    on Linux.
Makefile: 
    Since there is only one file, you can compile it with either 'make all'
    or 'make cat'. 'make clean' will delete all executables.
Execution: ./cat <filename> ...
    <filename> is the name of the file you wish to see.
    Multiple files can be read by separating filenames with a space.
