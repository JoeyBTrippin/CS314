cat.c: program code is a self implementation of the basic cat function
    on Linux.
Makefile: 
    Since there is only one file, you can compile it with eather 'make all' or 'make cat'.
Execution: ./cat <filename> ...
    Where <filename> is the name of the file you wish to see.
    Multiple files can be used. Simple seperate the filenames with a space.
